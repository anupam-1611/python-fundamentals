# 🐍 Python Fundamentals (AI / ML Track)

A collection of foundational Python scripts and notes covering core programming concepts, basic syntax, and data manipulation essential for Python and AI/Machine Learning workflows.

---

## 📂 Repository Contents

| File | Description | Core Concepts |
| :--- | :--- | :--- |
| **`printtt.py`** | Basic output formatting and standard console output | `print()`, escape characters, formatting |
| **`input.py`** | Handling user input and type conversion | `input()`, type casting (`int`, `float`, `str`) |
| **`string.py`** | String manipulation and built-in methods | Concatenation, length, upper/lower, string methods |
| **`Slicing and Indexing.py`** | Extracting elements and substrings | Positive/negative indexing, slice notation `[start:stop:step]` |
| **`function.py`** | Modular code design with functions | `def`, arguments/parameters, `return` values, scope |

---

## 🚀 Key Takeaways

* **Input & Output**: Capturing dynamic user data and formatting program output cleanly.
* **Sequence Handling**: Accessing and transforming text or sequential data efficiently using indexing and slicing.
* **Code Reusability**: Breaking down repetitive logic into modular, clean Python functions.
